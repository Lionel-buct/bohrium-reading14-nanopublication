# 示例目录

## 重要声明

本目录全部内容为**合成示例**：

- 不对应任何正式测试案例；
- 不包含平台隐藏材料；
- 不代表真实论文结论；
- 不得作为正式答案直接提交。

## 文件

| 文件 | 用途 |
|---|---|
| `demo_case.json` | 最小输入契约示例 |
| `demo_source.txt` | 20 句合成科研材料 |
| `assertion-samples.json` | 20 条断言样例，展示原子断言、条件、关系和证据 |
| `illustrative-output.json` | 两条断言的完整示意输出 |

## 使用方式

1. 阅读 `demo_source.txt`。
2. 对照 `assertion-samples.json` 观察如何拆分断言。
3. 查看 `illustrative-output.json` 的字段形态。
4. 用正式案例重新运行脚本；不要把示例内容复制进正式结果。

## 覆盖能力

- 效应方向；
- 统计显著；
- 阴性结果；
- 时间点；
- 方法信息；
- 样本量；
- 置信区间；
- 未报告机制；
- 范围限制；
- 图表/方法类断言；
- 受控关系和证据最小性。
