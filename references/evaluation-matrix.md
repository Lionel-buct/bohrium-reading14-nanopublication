公平对照说明：

- 平台负责基础 Agent 与加载 Skill 的 Agent 对照。
- 本 Skill 不伪造对照分数。
- 本 Skill 只记录可复核产物：覆盖数、证据数、精确定位率、警告数、重复数、未解决数。

## 3. 创新增益（15 分）

| 评分点 | 分值 | 本 Skill 的方法改进 |
|---|---:|---|
| 新增能力 | 5 | 断言、证据和来源链路一起生成，而不是只输出摘要 |
| 方法改进 | 5 | 契约优先输出、最小证据判据、受控关系词表、去重键、OCR 合并和跨图表证据拆分 |
| 创新证据 | 5 | 通过代码、规则文档、20 条示例和负例测试展示可运行边界 |

相对基础 Agent 的边界：

- 基础 Agent 容易把整段结论塞进一个字段，难以稳定给出定位。
- 本 Skill 把“可判断真假”“证据最小充分”“来源可追溯”变成结构化必填字段和机械检查。
- 本 Skill 不声称自动完成科学真值判断；语义合理性仍需人工/评审复核。

## 6. GitHub 公开作品链接（5 分）

本题可额外提交一个无需登录即可访问的 GitHub 仓库、目录或文件链接。

提交前要求：

1. 将本次 `submission/` 目录中的 Skill 和必要资源发布到公开仓库。
2. 用未登录浏览器确认链接可访问。
3. 在提交目录根路径的 `GITHUB_URL.txt` 第一行填写真实链接。
4. 如一个仓库包含多个作品，第二行填写本次作品在提交目录中的相对路径。

本 Skill 不会伪造公开链接，也不会把不存在的仓库写进提交材料。
